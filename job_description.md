# Jr. Web Developer – Job Opportunity

**Source**: Jobgether  
**Role**: Jr. Web Developer  
**Location**: Brazil / Latin America (Remote, Full-time)  
**Industry**: Security & IT / SaaS  
**Compensation**: USD $2,000–$2,500 / month  

---

## Role Overview
We are seeking a motivated junior web developer to help build and improve a modern web application that transforms meeting data into actionable insights. In this remote, full-time contract role, you will contribute to both frontend interfaces and backend APIs using TypeScript and related technologies. You will help turn transcripts, summaries, sentiment analysis, and key themes into clear dashboards and sponsor reports. Working closely with the team, you will build responsive, accessible user experiences and integrate the application with tools customers already use. You will also participate in testing, debugging, and code reviews while incorporating customer feedback into product improvements. This opportunity is ideal for an English-proficient developer who enjoys learning, adapting to change, and delivering practical solutions in a collaborative environment.

---

## Accountabilities
- Build, maintain, and improve features across a TypeScript web application, including user interface components and supporting APIs.
- Transform meeting data, including transcripts, summaries, sentiment, and identified themes, into intuitive dashboards and sponsor-facing reports.
- Develop responsive, accessible interfaces that deliver a consistent experience during demonstrations and live events.
- Help integrate the application with customer tools and platforms, including customer relationship management (CRM) systems.
- Write and maintain automated tests, troubleshoot issues, fix bugs, and participate in code reviews.
- Collaborate directly with team members to understand customer feedback and translate it into useful product enhancements.
- Contribute to the ongoing improvement of application functionality, usability, and reliability.
- Communicate progress, ask questions, and incorporate feedback to support continuous learning and effective delivery.

---

## Requirements
- Between 1 and 3 years of professional web development experience; relevant internships, bootcamp experience, or strong personal projects may also be considered.
- Solid understanding of TypeScript and JavaScript fundamentals.
- Experience with a modern frontend framework, preferably React.
- Good knowledge of HTML, CSS, and responsive web design principles.
- Basic understanding of REST APIs and working with application data.
- Familiarity with Git and collaborative software development workflows.
- Clear English communication skills, both written and verbal.
- Strong attention to detail, curiosity, adaptability, and a proactive approach to learning and problem-solving.
- Ability to collaborate effectively with teammates and respond constructively to feedback.
- Current residence in Latin America, with the ability to work remotely and commit to a full-time schedule.
